# Governance and Accountability Tests

Concise pytest module names:
- `test_final.py`: final cross-file and package-integrity checks.
- `test_routing.py`: routing, privacy, permissions, and anonymous intake.
- `test_investigation.py`: investigations, evidence, and corrective actions.
- `test_runtime.py`: deep runtime-readiness contracts.
- `test_workspace.py`: workspace, retention, and scheduled-task checks.
- `test_security.py`: security, company scope, CAPTCHA, and tracking checks.
- `test_reports.py`: reports, portal, templates, notifications, and dashboards.
- `test_risk.py`: enterprise risk, compliance, and assurance.
- `test_retirement.py`: safe retirement of the obsolete procurement complaint source.

Pytest discovers all modules because every filename keeps the `test_*.py` pattern.
